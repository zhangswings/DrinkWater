# DrinkWater v0.1.0

首次 macOS 下载版本。以下文案在验证通过后用于正式 Release。

## 已有能力
- 工作日 10:00–17:00 整点提醒，支持菜单栏立即提醒。
- 提醒弹窗不抢焦点；飞入、飞出、水杯动画和每 30 秒增大效果。
- 默认 ⌘1 关闭提醒，支持预设、自定义快捷键及偏好持久化。
- 优先在内置屏幕显示，无通知权限依赖。

## 本次发行工程
- 增加 Universal 2 应用包、ZIP/DMG 构建和签名公证流程。
- 修复 A 键（键码 0）保存后被错误回退为默认键的问题。

## 安装与限制
要求 macOS 13+。验证通过后支持 Apple Silicon 和 Intel。下载 DMG，将应用拖入 Applications；或解压 ZIP 后移动应用。安装无需 Xcode/Swift。
应用需要保持运行，按 Mac 当前本地时间提醒。时段固定，未提供登录启动或自动更新。快捷键仅在弹窗时注册，冲突时请更换组合。
升级前退出应用，再替换旧版。MIT 开源。

发布前必须将本段替换为实测架构、系统版本和签名公证结果，并附 source commit 与 SHA256SUMS.txt；不得提前声称验证通过。
